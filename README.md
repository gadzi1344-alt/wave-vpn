# Wave VPN — тестовый Telegram-бот для Cloudflare Workers и H1/VLESS

Бот работает отдельно от VPN-сервера: показывает инструкции и индивидуальные ссылки, созданные администратором в панели H1/VLESS. Запускайте только после настройки своих аккаунтов. Логика проверена с имитацией Telegram и KV; реальное развёртывание и подключение к серверу не выполнены.

## Возможности и ограничения
- Русскоязычное меню: подписка, инструкция Happ, поддержка и Telegram ID.
- Администратор вручную выдаёт персональную ссылку и удаляет её из бота.
- Защищённый Telegram webhook; бот отвечает только в личном чате.
- Нет автоматического API H1, оплаты, автоматической регистрации, проверки VPN, истечения подписок или Telegram Mini App. Это тестовая версия.
- `/revoke` **не отключает VPN**: для этого отдельно отзовите пользователя в панели H1/VLESS. KV хранит ссылки, поэтому доступ к Cloudflare-аккаунту и KV необходимо ограничить. Изменения KV могут распространяться с задержкой.

## Необходимо
- VPS/готовый VPN-сервер с панелью H1/VLESS и персональными VLESS-ссылками или ссылками подписки для Happ.
- Telegram-бот от @BotFather. Сохраняйте токен в тайне и не отправляйте его в чат.
- Cloudflare-аккаунт с Workers и KV, Node.js и Wrangler на вашем компьютере; тарифы Cloudflare могут иметь ограничения.

## Установка
Откройте эту папку в терминале на своём компьютере. Не публикуйте токены.

1. Авторизуйтесь в Cloudflare: `npx wrangler login`
2. Создайте хранилище: `npx wrangler kv namespace create WAVE_KV`
3. Полученный ID вставьте в `wrangler.toml` вместо `REPLACE_WITH_KV_NAMESPACE_ID`; имя binding `WAVE_KV` не меняйте.
4. Настройте секреты, вводя их только в запрос терминала:
```sh
npx wrangler secret put BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
```
`BOT_TOKEN` — токен BotFather. `WEBHOOK_SECRET` — отдельная случайная строка латинских букв, цифр, `_` или `-` длиной 1–256 символов; сохраните её для следующего шага.
5. Опубликуйте: `npx wrangler deploy`. Запишите HTTPS-адрес Worker из результата. При необходимости настройте собственный публичный домен Worker.
6. Запустите `bash setup-webhook.sh`, введите HTTPS-адрес Worker без `/telegram`, токен BotFather и тот же `WEBHOOK_SECRET`. Скрипт зарегистрирует webhook в Telegram; старый webhook бота будет заменён.
7. Откройте бота в Telegram, нажмите Start и отправьте `/id`. Затем задайте свой числовой ID в терминале: `npx wrangler secret put ADMIN_ID`.
8. Чтобы указать контакт поддержки, настройте `SUPPORT_USERNAME` в `wrangler.toml`, затем снова запустите `npx wrangler deploy`.

## Как протестировать
1. Пользователь открывает бота и присылает вам свой ID из `/id`.
2. В H1/VLESS создайте отдельного клиента и скопируйте для него ссылку подписки или VLESS-ссылку для Happ. Не используйте общую ссылку для разных людей.
3. Администратор в личном чате с ботом отправляет команду, заменив ID и ссылку своими:
```text
/grant 123456789 https://ваша-подписка/ссылка
```
Поддерживаются `https://` и `vless://` без пробелов. Бот попытается удалить сообщение с ссылкой, но удаление не гарантировано: если оно осталось, удалите вручную. Ссылка также остаётся в чате пользователя и в Cloudflare KV. Не пересылайте её посторонним.
4. Пользователь выбирает «Моя подписка» и добавляет полученную ссылку в Happ. Проверьте фактическое подключение к VPN.
5. Удалить ссылку из бота: `/revoke 123456789`. Отдельно отключите ключ клиента в H1/VLESS: удаление из бота не отзывает уже скопированную ссылку.

Одна ссылка на пользователя. Выдача/удаление может появляться с задержкой из-за KV. Дальнейшая интеграция с H1 API требует отдельно проверить доступ к API и корректный доверенный TLS-сертификат; не отключайте проверку сертификатов.

## Локальная проверка
`node test.mjs` проверяет логику на имитациях; это не проверка живого Telegram, Cloudflare, H1/VLESS или Happ.
